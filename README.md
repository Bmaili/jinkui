# 金匮

个人用的安卓密码管理器。密码加密后同步到你自己的 GitHub 私有仓库或阿里云 OSS，多台设备双向同步。

> 开发中，还不能使用。进度见 [SPEC.md](SPEC.md) 第 9 节。

## 设计要点

- **没有服务器**：数据只在你的手机和你自己的云端存储里。
- **全程加密**：本地和云端都只存密文，格式是开放的 [age](https://age-encryption.org)。就算这个 app 不能用了，在电脑上装个 age 也能解开（云端仓库里的 `README.md` 写了步骤）。
- **多设备不丢修改**：每台设备只写自己的文件，读取时合并。两台设备同时改了同一条密码，一个是当前值，另一个在历史里，不会被悄悄覆盖。
- **主密码是唯一的钥匙**：忘了主密码、又丢了所有设备，就再也解不开。没有找回功能。
